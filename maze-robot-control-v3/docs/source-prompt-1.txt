# 43. PATH TRANSFER PROTOCOL

For large path uploads, design a more robust protocol than blindly sending a string.

For example:

```text
PATH_BEGIN,12
PATH_CHUNK,LFRLFRRBFLRR
PATH_END
```

Robot response:

```text
ACK,PATH_BEGIN
ACK,PATH_CHUNK
ACK,PATH_END
PATH_STORED,12
```

A checksum or CRC is optional but encouraged.

For example:

```text
PATH_END,CRC32
```

The firmware should validate the path before running it.
