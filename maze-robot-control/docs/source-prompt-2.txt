# 65. IMPORTANT LIMITATION

Do not claim that literally every possible picture can automatically be converted perfectly.

If the system cannot confidently interpret an uploaded maze, it must report:

```text
Maze extraction requires correction.
```

Then open the maze editor.

The system should make a **best effort to support arbitrary maze layouts**, while always allowing manual correction.

This is preferable to generating an incorrect maze silently.
